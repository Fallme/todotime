# TodoTime
线上地址：https://todotime-mauve.vercel.app/

TodoTime 是一个个人番茄钟与任务管理工具。首次使用需要创建或输入个人同步识别码，任务、设置和统计数据会同步到服务端配置的独立私有存储。

> 专注、任务与成长趋势，一处管理。支持中文 / English 即时切换，使用专属码跨设备同步独立个人数据。

推广介绍与可直接使用的中英文发布文案见 [推广素材](docs/PROMOTION.md)。

## 核心能力

- 任务支持每日、隔日、隔二日、指定星期与每月指定日期自动刷新；每月日期通过弹出月历多选。到期恢复时保留累计番茄、专注记录与完成历史。当前月已完成任务留在列表底部，上月及更早记录按月折叠归档。
- 计时圆环从满环开始顺时针逐步变空，指针始终贴在剩余弧线头部；默认每轮含 4 组，轮次点末尾的纯图标可结算并跳过整轮、归零全部组次，控制区图标则只跳过当前专注或休息阶段。
- 顶部提供多组中英文激励语，定时随机轮换，也可手动刷新。
- 番茄工作、短休息、长休息循环，可自定义时长和长休息间隔。
- 满 1 分钟保存专注时长，满 15 分钟计 1 个番茄；自然结束和手动结束规则一致。
- 支持手动补录遗漏的专注，可关联已有任务、即时新建任务或不关联任务；补录按当前设置的一轮工作时长计算完整番茄，剩余时长达到 15 分钟再加 1 个；补录时新建的任务默认为已完成，并按补录结束时间进入完成记录。
- 新任务开始、暂停、继续、结束、进入休息与完成整轮均有不同提示音，底部导航适配手机、平板、桌面和安全区。
- 近七天/近一个月统计使用“专注时长 + 番茄 + 完成任务”三组方形柱状图，饼图可切换三类板块分布。
- 跳过工作会保存已达到门槛的时长和番茄，并始终推进当前组次。
- 主任务、子任务、板块分类、完成、放弃、恢复、软删除和历史归档。
- 专注记录按结束当时的任务归属；未选任务时可在轮次结束后分配。
- 今日、近七天、近一个月统计，以及周报、月报和板块占比。
- 每个个人同步识别码拥有完全隔离的本地缓存和云端 JSON 数据。
- 多设备使用设备级唯一任务/记录 ID；专注记录和任务番茄事件分别计算后取并集，避免同时使用造成计数覆盖。
- 首次入口与完整应用界面支持中文 / English 切换，语言偏好保存在当前设备。
- 25 套可同步主题：设置页一行显示当前主题，点击进入二级选择弹窗；默认番茄始终排在首位，并包含液态玻璃、中国画、水墨画、版画雕刻、金属质感、彩色玻璃、塔罗牌、动漫、星露谷·泰拉，以及苹果极简、手绘纸张、像素游戏、黑白秩序、苏联色块、3D 潮玩、油画质感、现代构成、简笔画、儿童蜡笔画、赛博霓虹、抹茶自然、海洋蓝调、纸墨东方和星夜深蓝。
- 本地离线优先，恢复网络后自动合并；同一条任务按 `updatedAt` 较新版本获胜。

详细规则见 [功能说明](docs/FEATURES.md)，当前验证结果见 [测试报告](docs/TEST_REPORT.md)。

## 数据与安全

- `Fallme/todotime`：程序代码，不保存个人任务数据。
- 独立 Private 数据仓库：保存用户配置和统计历史；具体位置只配置在部署服务端，不进入前端页面或前端代码。
- 云端目录：`profiles/<识别码哈希>/config.json` 与 `profiles/<识别码哈希>/history.json`。
- 服务端以 SHA-256 哈希后的目录区分用户，不把原始识别码写入仓库。
- GitHub Token 只存在于 Vercel 服务端环境变量，前端无法读取。
- 识别码本身相当于个人数据访问凭证，无法找回，不应公开分享。

## 同步节奏

- 设置或任务编辑：停止编辑 2.5 秒后合并同步。
- 专注历史：记录变化 1.5 秒后合并同步。
- 页面运行期间：每分钟双向合并任务、设置与统计历史，并把本地缺失记录补回云端。
- 返回页面：距离上次同步满一分钟时立即执行一次完整双向合并。
- 页面刷新、关闭或进入后台前，会尽力立即写出尚未同步的数据。
- 完成专注或改变任务状态时立即保存；专注每跨过一个完整分钟，统计图立即更新并冲刷待同步数据。
- 进行中的专注每分钟更新同一条检查点记录，结束时转为正式记录，不重复累计；意外刷新可恢复到最后一个完整分钟。
- 浏览器会保留最近历史缓存；云端为空或版本较旧时不能覆盖本地已有任务和专注记录。
- 内容没有变化时不提交 Git，避免产生无意义版本。

## 部署变量

在 Vercel 项目中配置：

```text
GITHUB_TOKEN=<仅有私有数据仓库 Contents 读写权限的 fine-grained token>
GITHUB_DATA_REPO=owner/private-data-repository
```

前端和 API 分属不同域名时，可额外配置：

```text
SYNC_ALLOWED_ORIGIN=https://your-todotime-domain.example
```
