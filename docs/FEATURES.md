# TodoTime 功能说明

## 1. 使用模式

### 1.1 本地模式

- 首次打开且未启用识别码时，数据只保存在当前浏览器。
- 断网不影响任务编辑、计时和统计查看。
- 本地模式不会调用 GitHub 同步接口。

### 1.2 个人同步模式

- 点击“生成新识别码”，复制保存后点击“启用新识别码”，当前本地数据会归入该身份。
- 在其他设备输入同一识别码并点击“加载已有识别码”，会加载该身份的设置、任务和统计。
- 不同识别码的本地缓存及云端文件完全分开。
- 识别码默认以密码形式隐藏，可临时显示或复制。
- “清除数据”只清除当前身份在本机的缓存并退出，不删除云端数据，也不影响其他识别码。

## 2. 任务管理

- 可创建主任务，并选择所属板块。
- 任务支持完成、取消完成、放弃、恢复和软删除。
- 每个主任务可添加子任务；子任务同样支持完成、放弃、恢复、删除和直接开始专注。
- 可新增、重命名、改色和删除板块；至少保留一个板块。
- 删除板块时，原板块任务会移动到剩余板块。
- 任务列表支持全部、进行中、已完成、已放弃四种状态过滤。
- 三天前完成或放弃的任务进入按月份折叠的历史归档。
- 今日番茄数会合并本地和云端记录，并按记录 ID 去重。

## 3. 计时逻辑

### 3.1 标准循环

1. 进入工作阶段并开始倒计时。
2. 工作阶段自然结束后记录一次专注。
3. 未达到长休息间隔时进入短休息；达到间隔时进入长休息。
4. 短休息结束后自动开始下一次工作。
5. 长休息结束后停止，若存在未分配记录则要求先分配。

### 3.2 计时准确性

- 计时使用绝对截止时间计算剩余秒数，不依赖“每秒减一”。
- 浏览器切到后台或系统短暂卡顿后，恢复时会按真实经过时间校正。
- 暂停保留剩余时间；继续时从剩余时间重新计算截止时间。
- 每条记录使用 ISO 时间和本地日期，支持跨午夜记录分日统计。

### 3.3 任务归属

- 已选择主任务或子任务时，专注结束立即记录到当时选择的任务。
- 专注过程中切换任务，只影响切换后结束的记录，不会改写已经完成的记录。
- 没有选择任务时，记录进入待分配列表。
- 待分配记录不会自动归到后来临时选择的任务；用户可明确选择主任务、子任务或“其他”。

### 3.4 按钮规则

- “开始/暂停”：控制当前阶段。
- 左侧按钮“结束并记录本轮”：手动结束也按实际完成时长判断和保存。
- 满 1 分钟即保存一条专注时长记录；不足 1 分钟不保存。
- 满 15 分钟的专注记录才计为 1 个番茄，并增加所选任务的番茄进度；1–14 分钟只累计时长。
- 自然结束与手动结束使用同一套规则，旧记录未带番茄标记时按时长兼容判断。
- “跳过工作”：满 1 分钟保存实际时长，满 15 分钟才增加 1 个番茄；无论时长是否达标都会推进顶部组次，到组末时整组点亮并进入长休息，休息结束后清零。
- “跳过休息”：短休息会进入下一次工作；长休息会停止并处理未分配记录。
- 从任务的播放按钮快速开始：工作中只切换归属；暂停或休息时开启新的工作阶段。
- 开始专注使用明亮的双音提示；进入休息使用柔和下行提示，两者可在设置中统一关闭。

## 4. 统计与报告

- 今日概览：番茄数、专注分钟、完成任务数。
- 周/月趋势：在同一张双坐标组合图中用柱状图显示专注时长、两条折线显示番茄数与完成任务数，可切换近七天与近一个月。
- 板块占比：饼图可切换专注时长、番茄数和完成任务数的分类占比。
- 周报/月报：包含与上一周期对比、活跃天数、趋势图、板块分布和完成任务列表。
- 时长与数量使用独立坐标轴，避免数值尺度不同造成图表误读。
- 本地今日记录和云端历史按记录 ID 去重，避免重复统计。
- 日期采用本地日期计算，避免 UTC 时区导致当天数据偏移。
- 报告可下载为文本文件。
- 底部导航会随手机、平板和桌面内容宽度同步伸缩，并适配窄屏、矮屏和手机安全区。

## 5. 同步与冲突处理

- 配置文件保存设置和完整任务列表；历史文件按日期保存专注记录。
- 任务采用软删除，删除状态也能同步到其他设备。
- 同 ID 任务按 `updatedAt` 比较，更新时间较新的版本获胜。
- 专注记录按稳定记录 ID 合并去重。
- 写入前重新读取远端文件；GitHub 返回冲突时最多重试三次。
- 同步操作串行排队，避免配置与历史并发写入互相覆盖。
- 无内容变化时只更新本机同步状态，不创建 Git 提交。
- 当前统计界面加载最近 60 天；历史文件保留最近 400 天记录。
- 页面运行时每分钟双向合并配置、任务和统计历史；重新回到页面且距离上次同步满一分钟时立即执行。
- 页面刷新、关闭或进入后台前会尽力冲刷待同步数据，减少发布更新和浏览器挂起造成的保存窗口。
- 专注完成、任务状态变化时立即刷新统计并写入同步队列；计时每跨过一个完整分钟，今日时长与走势立即更新并冲刷待保存数据。
- 进行中的专注采用固定记录 ID 的分钟检查点覆盖保存，结束时原位转为正式记录，避免每分钟生成重复记录。
- 最近历史同时保存于当前身份的浏览器缓存与私有 GitHub 数据仓库，任一侧为空时只允许补全，不允许覆盖删除另一侧记录。
- 旧版本未分区的本地任务和今日专注记录会按原识别码恢复并并入当前身份，不删除旧数据键。

## 6. 数据导入导出

- 导出包括当前设置、任务和今日专注记录，不包含个人同步识别码。
- 导入可恢复设置和任务；当前设备的识别码保持不变。
- 导入数据后会按当前身份进入本地缓存，并按正常节奏同步。

## 7. 已知产品边界

- 识别码不是账户系统：没有邮箱、验证码、找回密码或后台管理页面。
- 知道识别码的人可以读取该身份的数据，因此必须像密码一样保管。
- GitHub JSON 适合个人、小规模低频同步，不适合多人实时协作或高频写入。
- 当前跨设备合并以任务级最后更新时间为准，不提供字段级冲突编辑器。
