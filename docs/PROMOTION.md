# TodoTime 推广介绍

## 中文短介绍

TodoTime 是一款轻量、专注且尊重个人数据的番茄钟任务工具。一个专属码即可在多台设备同步任务、番茄记录、统计和设置；不同专属码的数据完全隔离。它会自动记录每一分钟的专注，用清晰的趋势图、板块分布和智能周报/月报，帮助你看见投入如何转化为成果。

## 中文宣传语

专注不只需要倒计时，更需要被看见。TodoTime 把番茄计时、任务管理、多端同步和成长分析放进一个安静的工作空间。每一分钟实时保存，每一个完成都有记录，每周、每月都有针对你真实节奏的复盘建议。

## 核心卖点

- 专属码多端同步：无需复杂注册，同一码加载自己的完整数据。
- 多人数据隔离：不同专属码的任务、统计和设置互不混合。
- 真实计时规则：满 1 分钟记录时长，满 15 分钟累计番茄。
- 任务与专注联动：主任务、子任务、分类与番茄完成数统一管理。
- 可读的成长趋势：时长柱状图、番茄与任务折线、分类分布一目了然。
- 智能周期复盘：周报、月报根据趋势、连续性、投入产出和板块分配给出不同评价。
- 中英双语：首次进入和完整应用界面均支持中文、English 随时切换。
- 25 套专注氛围：新增中国画、水墨画、版画雕刻、金属质感、教堂彩色玻璃、塔罗牌、动漫与星露谷·泰拉风格；从番茄、液态玻璃、苹果、像素到油画、现代构成、简笔画、儿童蜡笔、黑白、苏联色块与 3D 潮玩，每套主题都有专属计时器表现。

## English short description

TodoTime is a calm Pomodoro timer and task workspace built around private, practical progress. One personal code syncs tasks, focus history, insights, and settings across devices, while different codes keep every profile completely separate. Every focused minute is saved and transformed into clear trends, category breakdowns, and smart weekly and monthly reviews.

## English launch copy

Focus deserves more than a countdown. TodoTime brings Pomodoro sessions, task planning, private cross-device sync, and meaningful progress reviews into one lightweight workspace. See every minute, every completed task, and the patterns that help you work better next week.
